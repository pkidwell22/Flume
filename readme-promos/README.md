# Flume — creative promo films

Original promotional films for the Flume README. These are creative pieces assembled outside
the Flume application; they do not demonstrate in-app generation or export.

## alien-reel/

**Flume / Alien Reel** (`flume-alien-v002.mp4`, 29.5 s, 1920×1080, 24 fps, silent by design)

A continuous morphing journey cut from original footage generated for Flume on 2026-10-18:

1. **Irradia** — an iridescent crystalline machine-flower assembling in a black void.
2. **Crystal → metal morph** — the flower's facets melt into channels of flowing liquid mirror.
3. **Mercury Flume** — the liquid-metal river pours through black volcanic glass.
4. **Metal → pasture morph** — the metal thins into night grass under a violet aurora.
5. **Signal Pasture** — circuit-veined creatures graze, resolving to a dimmed close.

The world-to-world bridges are first-and-last-frame guided metamorphosis clips generated from
boundary frames of the neighboring studies. The small centered Flume lockup (composed from the
repository's own `packages/ui/assets/flume-mark.svg` paths) appears only in the final four
seconds.

Files:

- `flume-alien-v002.mp4` — delivery master (H.264, verified 29.5 s / 708 frames / full decode)
- `flume-alien-v002-preview.gif` — lightweight README preview (mute)
- `flume-alien-v002-poster.png` — poster frame from the end card
- `composition.html` + `index.motion.json` — the HyperFrames composition that produced the film;
  it expects the five source clips in an `assets/` directory and is provided for provenance
  and rebuild, not as runnable app code
- `SHA256SUMS.txt` — integrity checksums for every published file
